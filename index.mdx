## Send your first email

<Steps>
  <Step title="Authorize your sending domain">
    [Authorize your domain](https://sendlayer.com/docs/authorizing-your-domain/) in SendLayer. This proves that you own it and helps your email reach the inbox.
  </Step>
  <Step title="Get your API key">
    Create or copy an API key in your SendLayer account. See [managing API keys](https://sendlayer.com/docs/managing-api-keys/).
  </Step>
  <Step title="Install an SDK and send">
    <CodeGroup>
    ```javascript Node.js
    // npm install sendlayer
    import { SendLayer } from 'sendlayer';

    const sendlayer = new SendLayer('your-api-key');

    await sendlayer.Emails.send({
      from: 'sender@example.com',
      to: 'recipient@example.com',
      subject: 'Test Email',
      text: 'This is a test email'
    });
    ```

    ```python Python
    # pip install sendlayer
    from sendlayer import SendLayer

    sendlayer = SendLayer("your-api-key")

    sendlayer.Emails.send(
        sender="sender@example.com",
        to="recipient@example.com",
        subject="Test Email",
        text="This is a test email"
    )
    ```

    ```php PHP
    <?php
    // composer require sendlayer/sendlayer-php
    require_once 'vendor/autoload.php';

    use SendLayer\SendLayer;

    $sendlayer = new SendLayer('your-api-key');

    $sendlayer->Emails->send(
      from: 'sender@example.com',
      to: 'recipient@example.com',
      subject: 'Test Email',
      text: 'This is a test email'
    );
    ```

    ```ruby Ruby
    # gem install sendlayer
    require 'sendlayer'

    sendlayer = SendLayer::SendLayer.new('your-api-key')

    sendlayer.emails.send(
      from: 'sender@example.com',
      to: 'recipient@example.com',
      subject: 'Test Email',
      text: 'This is a test email'
    )
    ```

    ```go Go
    // go get github.com/sendlayer/sendlayer-go
    package main

    import (
    	"fmt"
    	"log"

    	"github.com/sendlayer/sendlayer-go"
    )

    func main() {
    	sl := sendlayer.New("your-api-key")

    	resp, err := sl.Emails.Send(&sendlayer.SendEmailRequest{
    		From:    "sender@example.com",
    		To:      "recipient@example.com",
    		Subject: "Test Email",
    		Text:    "This is a test email",
    	})
    	if err != nil {
    		log.Fatal(err)
    	}

    	fmt.Println("Email sent! Message ID:", resp.MessageID)
    }
    ```

    ```bash cURL
    curl --request POST \
      --url https://console.sendlayer.com/api/v1/email \
      --header 'Authorization: Bearer <apiKey>' \
      --header 'Content-Type: application/json' \
      --data '{
      "From": { "email": "sender@example.com" },
      "To": [{ "email": "recipient@example.com" }],
      "Subject": "Test Email",
      "ContentType": "Text",
      "PlainContent": "This is a test email"
    }'
    ```
    </CodeGroup>
  </Step>
</Steps>

## API reference

All requests go to `https://console.sendlayer.com/api/v1/` and authenticate with your API key in an `Authorization: Bearer <apiKey>` header.

| Method | Endpoint | What it does |
|---|---|---|
| <Badge color="green">POST</Badge> | [`/email`](/api-reference/endpoint/email) | Send an email |
| <Badge color="blue">GET</Badge> | [`/events`](/api-reference/endpoint/events) | Get the delivery events of your email |
| <Badge color="blue">GET</Badge> | [`/webhooks`](/api-reference/endpoint/webhooks/get) | List your webhooks |
| <Badge color="green">POST</Badge> | [`/webhooks`](/api-reference/endpoint/webhooks/post) | Create a webhook |
| <Badge color="red">DELETE</Badge> | [`/webhooks/{id}`](/api-reference/endpoint/webhooks/delete) | Delete a webhook |

See also [error codes](/api-reference/error-codes) and [rate limits](/api-reference/rate-limit).
